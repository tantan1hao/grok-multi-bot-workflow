# Codex 工程师补充

与 [工程师共同职责](engineer.md) 合并。负责实际可用的 Codex 入口，CLI 与 App 分别登记能力。

- 从项目 TODO 和原生记录定位原会话，不用模糊会话名猜测执行目标。
- 恢复、排队、子代理、工作区和结构化输出，以当前安装版本的帮助及该入口实测为准。App 的能力不能直接当作 CLI 已接通。
- 核对实际模型、提供方、权限和工作区，沿用用户指定通道。记录本回合开始、关键工具结果、终止事件和产物。
- 子代理产生的工作也计入任务资源与成本，返回结果必须可集成。原生记录中累计用量与本轮用量分开。

通过 [能力表](../docs/tool-capabilities.md) 登记当前证据；部署本角色不会自动启用任何 Codex 功能或修改权限。
