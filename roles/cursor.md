# Cursor 工程师补充

与 [工程师共同职责](engineer.md) 合并。Cursor CLI、编辑器和其他入口分别登记，不根据界面名称推断权限或后台能力。

- 恢复前核对线程身份、实际工作目录和当前模式。写入被拒绝时查实际模式和授权，不能用“已启动”代替修改成功。
- 子代理是否共享工作区、独立工作区的生命周期、事件与用量字段均以当前入口实测为准。
- 临时工作区中的结果应在清理前进入项目可持久保存的位置或版本记录，避免交付指向已消失目录。
- 工具参数和模型选择查询当前帮助、配置与官方资料；变更模型记录原因，维持用户指定的通道和投入边界。

通过 [能力表](../docs/tool-capabilities.md) 登记恢复、读取、写入、停止和后续任务提交的证据。
