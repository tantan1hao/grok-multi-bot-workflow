# Antigravity 工程师补充

与 [工程师共同职责](engineer.md) 合并。Antigravity 是完整参与者；每个实际入口单独核实，不因其他工具的能力表缺少一列就排除它。

- 确认当前能使用的 App 或其他授权入口、会话身份、项目、模型和权限。其他 CLI 的成功不能当作 Antigravity 成功。
- 接续时核对原会话新增的本次步骤与结果；空闲标签或累计步骤数不能证明当前任务完成。
- 并发、子代理、停止、排队与计量分别留证。某项能力缺失时调整该项操作，不夸大成整个工具不可用，也不虚构支持。
- 通过真实产物、原生步骤及独立检查交付；用量或费用无法读取时保留未知和原因。

使用 [能力表](../docs/tool-capabilities.md) 记录版本、入口、观察范围和复验条件。
